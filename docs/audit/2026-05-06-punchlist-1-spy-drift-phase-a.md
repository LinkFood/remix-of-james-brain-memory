## Step 3 — Cause class

**Primary cause: (b) Time-window-semantics-drift.** The two structured-return organs (`morning_brief`, `eod_summary`) compute SPY return over **different windows by design**:
- `morning_brief` is "what did the market do yesterday vs the day before" (close-to-close, 1-day return for the AM digest).
- `eod_summary` is "what did the market do during the session that just closed" (intraday open-to-close, session-only move).

These are **legitimately different metrics**. They will always differ by the overnight gap.

**Compounding factor: (c) Source drift partial.** Different upstream sources reach the two organs (Finnhub external vs internal flow computation), but both produce correct values for their respective windows.

**Hypothesis NOT confirmed:** (a) SPX-vs-SPY (REFUTED — both query SPY ETF). (e) Decimal/unit confusion (REFUTED — both report percent).

**Specialist_recall's "+0.9%" attribution remains unverified.** Possibly trading-session memory of a text mention rather than structured field. Pre-flag for separate follow-on (NOT load-bearing for this Phase A's gating decision).
