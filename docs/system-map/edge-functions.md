# Edge Functions — System Map

**163 edge functions audited 2026-05-02.** Read-only inventory: every function has a row regardless of LIVE/DORMANT/DEAD status.

## Schema

- **purpose** — 1-sentence summary from JSDoc/header
- **trigger** — `cron` (with schedule) / `http` (external) / `internal` (called by another fn) / `chat` / `agent`
- **tables_read / tables_written** — from .from('X') patterns
- **rpcs_called** — from .rpc('X') patterns
- **called_by** — caller functions or cron names
- **claude** — `Y` if function imports callClaude/CLAUDE_MODELS
- **status** — LIVE / DORMANT / DEAD / ?

## Audit caveats

- TSV baseline used `from('X').select(...)` patterns — misses **6 ingesters** that write via raw REST POST (ct-event-calendar-ingester, ct-indicator-events-ingester, ct-insider-ingester, ct-institutional-ingester, ct-political-ingester, ct-prediction-markets-ingester). Their `tables_written` may show as empty but they DO write via `${SUPABASE_URL}/rest/v1/<table>?on_conflict=...` patterns.
- Specialist functions (10 ticker-specific) all import `runSpecialistWakeup` from `_shared/specialistRunner.ts` — real logic + tables live there, not in the 56-line specialist files.
- Cluster detectors (`cluster_default`, `cluster_slow_stacker`) are NOT standalone functions — they're `ct_detectors` rows consumed by the cluster loop in `ct-signature-watcher`.
