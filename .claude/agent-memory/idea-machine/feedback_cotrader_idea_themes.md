When generating Co-Trader ideas, lean toward these themes:

- **Self-awareness / bias layer** — ideas where Claude learns its own mistake patterns (self-grader, lessons-curator, confession booth) are core thesis, not nice-to-haves.
- **Commitment devices / pre-registered calls** — gauntlets, locked pre-bell predictions, conviction decay curves. Forces honest calibration, no hindsight narration.
- **Visceral P&L / ghost positions** — track-record-as-equity-curve beats abstract accuracy metrics. He's a day trader; he thinks in charts and dollars.
- **Context-aware aggression** — system knows when James is AFK (calendar), when market regime shifts, when confidence should scale.
- **Memory-as-analogy** — use 512-dim embeddings to find historical rhymes, not just search. "Today looks like Mar 14" is a real feature.
- **Cross-pollination with JAC infra** — calendar, Slack, voice, code agent, research agent, Brain are free levers he already owns.
- **Adversarial / second-opinion agents** — red-team Claude, forced corroboration from independent sources.
- **Behavioral/emotional capture** — voice journal, tap-to-log Slack buttons. Things Claude can't see from tape alone.

**Why:** These themes map directly to the stated core edge thesis and have landed in past sessions. Ideas that ignore them (e.g., generic charting features, UI polish) feel like filler.

**How to apply:** When building an idea list, ensure at least half the picks hit one of these themes. Pure tape-reading suggestions without a self-awareness/memory/commitment angle are weaker picks.
